# 📚 Library App Clone

A fully responsive **Library Web App Clone** built with **HTML, CSS, and JavaScript**, designed to simulate a modern online bookstore experience with dynamic rendering, filtering, and clean UI structure.

## 🧠 Features

* 📖 Dynamic book rendering using JavaScript
* ⭐ Star-based rating system (supports half-stars)
* 💲 Smart pricing logic (sale vs regular pricing)
* 🔽 Filter system:

  * Price (Low → High)
  * Price (High → Low)
  * Rating
* ⏳ Simulated API loading (Promise + setTimeout)
* 📱 Fully responsive design
* 🍔 Mobile navigation menu

---

## 🛠️ Tech Stack

* **HTML5** – Semantic structure
* **CSS3** – Flexbox, responsive layout, UI styling
* **JavaScript (ES6+)** – DOM manipulation, sorting, async logic

---

## ⚙️ How It Works

* Books are fetched using a **mock API (Promise)**
* Data is dynamically rendered into the DOM
* Sorting is handled using JavaScript `.sort()` methods
* Ratings are generated programmatically with icons
* Pricing conditionally displays sale vs original price
